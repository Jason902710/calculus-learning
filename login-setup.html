啟用 Google 登入

後端與網站已連接。還需要網站擁有者在 Google 建立登入應用，並將設定填進 Supabase。

1. Google 登入應用

前往 Google Auth Platform，選取或建立自己的專案，設定應用名稱、聯絡信箱與 External 使用者。只要求 openid、email、profile。

在 Clients 建立「Web application」類型的 OAuth client。

Authorized JavaScript origins：

https://jason902710.github.io

Authorized redirect URIs：

https://qvkstpayrpubylqsjehn.supabase.co/auth/v1/callback

若應用仍為 Testing，將自己及測試學生加入測試名單。正式開放前依 Google 畫面要求發布應用。

2. 啟用 Supabase Google provider

在 Supabase 登入服務設定 啟用 Google，填入 Client ID 與 Client Secret。Secret 只放在這個後端設定，不要傳到聊天或放進網站原始碼。

Authentication → URL Configuration 的 Site URL 設成：

https://jason902710.github.io/calculus-learning/

Redirect URLs 同時加入：

https://jason902710.github.io/calculus-learning/
https://jason902710.github.io/calculus-learning/admin.html

3. 指定管理者

回網站用自己的 Google 帳號登入。登入不會自動取得管理權限，請告知網站維護者核對帳號，再從後端指定管理者。學生不能自行升權。
