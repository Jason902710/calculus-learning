管理者登入

使用你的 GitHub 管理金鑰登入。金鑰只在本分頁記憶體中使用，重新整理或登出後清除。

第一次使用：設定管理金鑰
  1. 開啟 GitHub 金鑰設定，登入自己的帳號。
  2. 名稱可填「循理教材管理」，設定到期日。
  3. Repository access 選 Only select repositories，只選 calculus-learning。
  4. Repository permissions 加入 Contents：Read and write，其他維持預設。
  5. 產生後，將金鑰貼在下方。不要傳到聊天或分享給學生。

教材檔案

相同位置與分類已有教材時，會更換該檔案。

教材將公開，所有取得網站連結的人都能閱覽及下載。

發布後需等待 GitHub Pages 更新，通常約 1–3 分鐘。刪除會移除網站連結與目前檔案，GitHub 版本紀錄仍會保留。
